# 🦥 校园懒人效率站

一个完整的校园跑腿服务平台，包含用户端、骑手端和管理后台，无需后端服务器，打开即可使用。

## 📁 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 项目展示页（宣传介绍） |
| `app.html` | **用户端** - 学生下单、查看订单 |
| `rider.html` | **骑手端** - 骑手接单、配送 |
| `admin.html` | **管理后台** - 订单管理、骑手管理、管理员管理 |
| `README.md` | 使用说明 |

## 🚀 快速开始

### 1. 打开项目展示页
双击 `index.html`，查看项目介绍页面。

### 2. 进入三端系统

#### 用户端 (app.html)
- 登录/注册（姓名、学号、手机号）
- 选择服务下单
- 查看订单状态和进度

#### 骑手端 (rider.html)
- 登录后查看待接订单
- 接单 → 开始配送 → 完成订单
- 查看收入统计

#### 管理后台 (admin.html)
- 默认总管理员账号：`admin` / `admin123`
- 查看数据概览和图表
- 管理订单、骑手、管理员

## ✨ 功能特性

## 🔐 权限系统

### 三端分离
| 端口 | 用户 | 可用功能 |
|------|------|----------|
| 用户端 | 学生 | 下单、查看订单、取消订单 |
| 骑手端 | 骑手 | 接单、配送、完成订单、查看收入 |
| 管理后台 | 管理员 | 订单管理、骑手管理、数据统计 |
| 管理后台 | 总管理员 | 以上 + 管理员管理、审批新管理员 |

### 管理员系统
- **总管理员**（默认账号：admin / admin123）
  - 可以添加/删除管理员
  - 审批新管理员申请
  - 拥有所有权限

- **普通管理员**
  - 订单管理
  - 骑手管理
  - 数据查看
  - 无法管理其他管理员

### 电话号码验证
所有端口注册/登录时，电话号码必须符合：
- 11位数字
- 以1开头
- 第二位为3-9
- 正则表达式：`/^1[3-9]\d{9}$/`

## 💾 数据存储

所有数据存储在浏览器 **LocalStorage** 中：
- `lazyOrders` - 订单数据
- `lazyRiders` - 骑手数据
- `lazyAdmins` - 管理员数据
- `lazyPendingAdmins` - 待审批管理员
- `lazyUser` - 当前登录用户
- `lazyRider` - 当前登录骑手
- `currentAdmin` - 当前登录管理员

⚠️ **注意**：清除浏览器数据会导致所有记录丢失，重要数据请及时导出备份！
